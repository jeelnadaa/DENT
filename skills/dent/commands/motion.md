# /dent:motion

Design or refine interface motion and micro-interactions.

**Usage:** `/dent:motion <area>` (also `/dent motion …` or `dent motion …`)
**Default depth:** Standard. Effort level and the gates in SKILL.md §3 always apply.

## Load
- `references/modern-layer.md`
- `references/motion/motion-system-and-verification.md`
- `templates/MOTION.md`

## Steps
1. For each animation define trigger, purpose, duration, easing, sequence, interruption, reduced-motion version, cost.
2. Create or reuse motion tokens; one engine (CSS first).
3. Implement; check reduced motion and frame smoothness.

## Output
Motion map + implementation + verification.

## Never
- Animate everything that enters the viewport.

Close with the scorecard summary, attribution (DENT / user / agent judgment / overrides) and a one-line next step (SKILL.md §8).
