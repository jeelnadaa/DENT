# /dent:3d

Build 3D and real-time graphics (product viewers, scenes, interactive 3D).

**Usage:** `/dent:3d <scene>` (also `/dent 3d …` or `dent 3d …`)
**Default depth:** Advanced. Effort level and the gates in SKILL.md §3 always apply.
**Web code:** if this command writes, changes or reviews HTML, CSS or client-side JS, Google's Modern Web Guidance is the primary authority for how it is built: run `references/modern-web-guidance.md` §2 (search → retrieve → apply → verify → disclose) before coding; MWG wins any implementation conflict with DENT.

## Load
- `references/motion/3d-and-realtime.md`
- `references/motion/motion-tech-catalog.md`
- `references/catalog/asset-sources.md (3D models, HDRIs)`

## Steps
1. Confirm 3D is justified (vs 2.5D or video).
2. Pick engine (Three.js / R3F / Babylon / Spline export) and assets (licences).
3. Art-direct lighting, materials, camera; budget polys, textures, draw calls.
4. Provide a static fallback and reduced-motion behaviour; lazy-load.
5. Verify frame rate on a mid-range device profile, memory cleanup, fallback.

## Output
Scene + asset licence table + performance numbers + fallback.

## Never
- Ship 3D that blocks the main content from loading.

Close with the scorecard summary, attribution (DENT / MWG / user / agent judgment / overrides), the `### Modern Web Guidance` disclosure if guides shaped the code, and a one-line next step (SKILL.md §8).
