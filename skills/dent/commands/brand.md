# /dent:brand

Create a mini brand / identity direction (logo direction, color, type, voice, sonic cue).

**Usage:** `/dent:brand <product>` (also `/dent brand …` or `dent brand …`)
**Default depth:** Standard/Advanced. Effort level and the gates in SKILL.md §3 always apply.
**Web code:** if this command writes, changes or reviews HTML, CSS or client-side JS, Google's Modern Web Guidance is the primary authority for how it is built: run `references/modern-web-guidance.md` §2 (search → retrieve → apply → verify → disclose) before coding; MWG wins any implementation conflict with DENT.

## Load
- `references/brand-identity.md`
- `references/creative/directions-library.md`
- `references/audio/sound-design.md` §5 (sonic logo)

## Steps
1. Concept + positioning in one line; category cliché named.
2. Logo direction (wordmark/symbol), color system (`scripts/palette.py`, color.md §12), type voice and pairing (`scripts/fonts.py`, typography.md §0), voice, optional sonic logo; ask where any imagery comes from (references/media-sourcing.md).
3. Show applications (favicon, OG image, app icon, header).
4. Record licences of fonts and any assets.

## Output
Brand sheet + assets + DESIGN.md brand section.

## Never
- Copy an existing brand's mark or style.

Close with the scorecard summary, attribution (DENT / MWG / user / agent judgment / overrides), the `### Modern Web Guidance` disclosure if guides shaped the code, and a one-line next step (SKILL.md §8).
