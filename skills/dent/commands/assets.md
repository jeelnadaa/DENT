# /dent:assets

Find, make and license icons, images, illustrations, favicons, OG images and other assets.

**Usage:** `/dent:assets <what you need>` (also `/dent assets …` or `dent assets …`)
**Default depth:** Quick/Standard. Effort level and the gates in SKILL.md §3 always apply.

## Load
- `references/catalog/asset-sources.md`
- `references/icons-illustration-and-imagery.md`
- `references/assets-and-marketing-graphics.md`

## Steps
1. Decide if imagery is needed and what role it plays.
2. Prefer project assets; otherwise pick a source from the catalogue and check its licence.
3. Produce correct sizes/formats; write alt text.
4. Record source + licence + attribution in DESIGN.md.

## Output
Assets + licence table.

## Never
- Use an asset whose licence you don't know.

Close with the scorecard summary, attribution (DENT / user / agent judgment / overrides) and a one-line next step (SKILL.md §8).
