# /dent:copy

Write or fix UX copy: headlines, CTAs, microcopy, errors, empty states.

**Usage:** `/dent:copy <screen or flow>` (also `/dent copy …` or `dent copy …`)
**Default depth:** Quick/Standard. Effort level and the gates in SKILL.md §3 always apply.
**Web code:** if this command writes, changes or reviews HTML, CSS or client-side JS, Google's Modern Web Guidance is the primary authority for how it is built: run `references/modern-web-guidance.md` §2 (search → retrieve → apply → verify → disclose) before coding; MWG wins any implementation conflict with DENT.

## Load
- `references/ux-writing.md`
- `references/creative/anti-slop.md` §4

## Steps
1. Find the voice (3 words) and the reader's job.
2. Write specific, front-loaded copy; one term per concept; verbs on buttons.
3. Replace generic marketing phrases with concrete outcomes; no invented numbers.
4. Proofread twice (gate G7).

## Output
Copy deck (location → text) with notes.

## Never
- Use 'Unlock', 'Seamless', 'Supercharge' or invented stats.

Close with the scorecard summary, attribution (DENT / MWG / user / agent judgment / overrides), the `### Modern Web Guidance` disclosure if guides shaped the code, and a one-line next step (SKILL.md §8).
