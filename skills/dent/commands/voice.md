# /dent:voice

Write and produce narration or voice-over (human or TTS) with captions.

**Usage:** `/dent:voice <script topic or video>` (also `/dent voice …` or `dent voice …`)
**Default depth:** Standard. Effort level and the gates in SKILL.md §3 always apply.

## Load
- `references/audio/voice-and-narration.md`
- `references/audio/audio-tech-catalog.md §4`
- `templates/SOUND.md §4`

## Steps
1. Ask: voice type, language/accent, and whether the user has a TTS/voice service or wants a free engine.
2. Write the script for the ear (short sentences, ~140–160 wpm), mark pronunciation and pauses.
3. Produce: record or synthesize; clean, level to target loudness.
4. Make captions/transcript; check sync and pronunciation.

## Output
Script, audio file(s), captions, licence/consent notes.

## Never
- Clone a real person's voice without documented consent.

Close with the scorecard summary, attribution (DENT / user / agent judgment / overrides) and a one-line next step (SKILL.md §8).
