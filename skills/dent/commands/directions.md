# /dent:directions

Explore 2–4 genuinely different creative directions before committing.

**Usage:** `/dent:directions <product>` (also `/dent directions …` or `dent directions …`)
**Default depth:** Standard. Effort level and the gates in SKILL.md §3 always apply.

## Load
- `references/creative-direction.md`
- `references/creative/directions-library.md`
- `references/creative/hero-typography.md`
- `references/styles/_styles-index.md`

## Steps
1. Write the category cliché for this product.
2. Pick 2–4 directions that differ on at least 3 axes (type, color, layout, imagery, motion, sound).
3. For each: name, concept sentence, palette swatches, type sample, hero composition, motion and sound idea, fits/risks.
4. Render a style tile per direction when HTML can be shown; recommend one.

## Output
Directions side by side with a recommendation; chosen one goes to the Decision Log.

## Never
- Offer three shades of the same idea.

Close with the scorecard summary, attribution (DENT / user / agent judgment / overrides) and a one-line next step (SKILL.md §8).
