# /dent:motion-graphics

Create motion graphics: kinetic typography, animated compositions, scroll stories, product animations, generative visuals.

**Usage:** `/dent:motion-graphics <piece>` (also `/dent motion-graphics …` or `dent motion-graphics …`)
**Default depth:** Advanced. Effort level and the gates in SKILL.md §3 always apply.
**Web code:** if this command writes, changes or reviews HTML, CSS or client-side JS, Google's Modern Web Guidance is the primary authority for how it is built: run `references/modern-web-guidance.md` §2 (search → retrieve → apply → verify → disclose) before coding; MWG wins any implementation conflict with DENT.

## Load
- `references/motion/motion-graphics.md`
- `references/motion/motion-menu.md`
- `references/motion/motion-tech-catalog.md`
- `references/motion/motion-system-and-verification.md`

- `templates/MOTION.md`

## Steps
1. Ask (if unknown): where it lives (web page, README GIF/SVG, video), length, sound on/off, dimension (1D/2D/2.5D/3D), which motion kinds and intensity (references/motion/motion-menu.md §1), and where any imagery, footage or music comes from (references/media-sourcing.md §2).
2. Concept → 2–3 motion directions (All-out) → storyboard with timing → animatic.
3. Choose technology with the selection ladder; justify it. For web pieces, retrieve the Modern Web Guidance guides for the effect first (scrollytelling, view transitions, motion).
4. Build with a timeline; design the reduced-motion version; budget performance.
5. Verify play-through, sync, loop point, frame rate, reduced motion, cleanup; capture video/GIF if useful.

## Output
MOTION.md (concept, storyboard, timing, tech), the piece, verification evidence.

## Never
- Add random particles/gradients without a concept.
- Make content wait for decoration.

Close with the scorecard summary, attribution (DENT / MWG / user / agent judgment / overrides), the `### Modern Web Guidance` disclosure if guides shaped the code, and a one-line next step (SKILL.md §8).
