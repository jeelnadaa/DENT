# /dent:motion-graphics

Create motion graphics: kinetic typography, animated compositions, scroll stories, product animations, generative visuals.

**Usage:** `/dent:motion-graphics <piece>` (also `/dent motion-graphics …` or `dent motion-graphics …`)
**Default depth:** Advanced. Effort level and the gates in SKILL.md §3 always apply.

## Load
- `references/motion/motion-graphics.md`
- `references/motion/motion-menu.md`
- `references/motion/motion-tech-catalog.md`
- `references/motion/motion-system-and-verification.md`
- `references/creative/directions-library.md (motion section)`
- `templates/MOTION.md`

## Steps
1. Ask (if unknown): where it lives (web page, README GIF/SVG, video), length, sound on/off, dimension (1D/2D/2.5D/3D), and which motion kinds and intensity (references/motion/motion-menu.md §1).
2. Concept → 2–3 motion directions (All-out) → storyboard with timing → animatic.
3. Choose technology with the selection ladder; justify it.
4. Build with a timeline; design the reduced-motion version; budget performance.
5. Verify play-through, sync, loop point, frame rate, reduced motion, cleanup; capture video/GIF if useful.

## Output
MOTION.md (concept, storyboard, timing, tech), the piece, verification evidence.

## Never
- Add random particles/gradients without a concept.
- Make content wait for decoration.

Close with the scorecard summary, attribution (DENT / user / agent judgment / overrides) and a one-line next step (SKILL.md §8).
