# /dent:type

Design hero titles and expressive typography (custom type compositions).

**Usage:** `/dent:type <headline or page>` (also `/dent type …` or `dent type …`)
**Default depth:** Standard. Effort level and the gates in SKILL.md §3 always apply.

## Load
- `references/creative/hero-typography.md`
- `references/typography.md`
- `references/modern-layer.md §7.1`

## Steps
1. Pick the type role: wordmark-scale, editorial, kinetic, typographic system, data-type.
2. Choose faces (licence checked) and a composition technique from hero-typography.md.
3. Build it fluid (clamp with rem), accessible (real text, not images), balanced wraps, reduced-motion safe.
4. Check it at 320 px and 1440 px; no overflow, no clipped letters.

## Output
The type composition in code + specimen + reasoning.

## Never
- Put essential text in images or canvas only.

Close with the scorecard summary, attribution (DENT / user / agent judgment / overrides) and a one-line next step (SKILL.md §8).
