# Brand Identity Basics

Use when the user has no brand yet (create a mini brand) or has one (apply it correctly).

---

## 1. If the user has a brand
Ask for: logo files (SVG preferred), brand colors (hex), fonts, guidelines PDF, voice notes, example materials. Then:
- Map brand colors to the 3-role structure (Dominant/Complement/Off) and semantic tokens; generate scales (color.md).
- If brand colors fail contrast for text/buttons, keep the brand hue but use a darker/lighter step for UI text and fills; record why in the Decision Log.
- Use brand fonts if licensed for web/app; otherwise suggest close free alternatives.

## 2. Mini brand (when there's none)
Create these, briefly, and confirm with the user:
1. **Positioning sentence:** "For [audience], [product] is the [category] that [key benefit], unlike [alternative]."
2. **Personality:** 3 adjectives + "this, not that" pairs (feeds style choice and voice).
3. **Name usage** (capitalization, never abbreviated, etc.).
4. **Logo direction** (below).
5. **Colors** (palette + roles).
6. **Typography** (display + body).
7. **Voice & tone** (ux-writing.md §2).
8. **Imagery/illustration direction** (icons-illustration-and-imagery.md, icons-illustration-and-imagery.md).

## 3. Logo types
| Type | Example form | Good for |
|---|---|---|
| **Wordmark** (logotype) | Name in custom/styled type | New brands, distinctive names |
| **Lettermark / monogram** | Initials | Long names |
| **Symbol / pictorial mark** | Icon of an object | Established brands |
| **Abstract mark** | Geometric shape | Tech, global brands |
| **Combination mark** | Symbol + wordmark | Most flexible; most common |
| **Emblem** | Name inside a badge | Vintage, institutional, food/drink |
| **Mascot** | Character | Playful, community brands |

## 4. Logo design principles
- **Simple** (recognizable at 16px favicon size and on a billboard), **memorable**, **timeless** (avoid trendy effects), **versatile** (works in one color, on dark/light, small/large), **appropriate** (fits audience).
- Design in black first; add color later.
- Build on a grid/geometry for balance; optical corrections over math.
- Avoid: gradients/thin lines that fail small, too many colors, stock-icon clichés (lightbulb, globe, swoosh), text too small inside emblems.
- The agent can draft simple logo concepts (SVG wordmarks/geometric marks) but should present them as concepts; professional logo design and trademark checks are recommended for real launches.

## 5. Logo system (deliverables)
- **Versions:** primary (horizontal), stacked, symbol-only, wordmark-only.
- **Color variants:** full color, one-color dark, one-color light (reversed), (optional) monochrome.
- **Clear space:** minimum empty space around the logo, defined by a unit from the logo (e.g. height of the symbol or the "x" of the wordmark).
- **Minimum size:** e.g. 24px tall digital (symbol 16px).
- **Misuse rules:** don't stretch, rotate, recolor, add effects, outline, place on busy backgrounds, or rearrange parts.
- **Files:** SVG (master), PNG @1x/2x/3x, favicon/app icon derived (assets-and-marketing-graphics.md).

## 6. Brand applications checklist
- Website/app UI, favicon & app icons, social profile images and cover images, OG/share images, email signature & templates, presentation template, business card/letterhead (if needed), merchandise basics, document templates.

## 7. Brand consistency
- Document everything in DESIGN.md (or a separate BRAND.md if the user wants).
- Same logo files, colors, fonts and voice across all touchpoints.
- Brand evolves deliberately — changes logged.
