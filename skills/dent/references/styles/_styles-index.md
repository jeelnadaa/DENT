# Aesthetic Styles — Index

Read this file first when the user names a style or describes a look. Find the style, then open ONLY that style's file.

## How to match the user's words to a style
1. Look for the style name or any alias in the table below.
2. If the user describes a feeling instead of a name, use "Pick by feeling" further down.
3. If two styles fit, pick the one that matches the **product type** better (each file's "Use for").
4. If nothing fits, use the closest style and say which one you used.
5. If the user gave no style at all, do not pick a loud one: use **Minimal** (tools, SaaS, docs) or **Premium Product** (marketing pages), with a default palette from `../color.md` (Part 2).

## Combining styles
- **One base style + at most one accent style.** Example: Bento (layout) + Dark Tech (visual); Minimal base + Kinetic Typography in the hero only.
- The base style owns tokens (color, type, radius, spacing). The accent style may only add its signature moves in limited places (hero, empty states, marketing sections).
- Never combine styles whose signature moves fight (e.g. Neumorphism + Neo-Brutalism, Luxury + Memphis).
