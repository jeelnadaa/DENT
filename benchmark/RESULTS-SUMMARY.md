# Benchmark results summary

_Read by the DENT landing-page prompt. Every number here comes from the linked RESULT.md files._

## Batch 2026-11-14: Claude Code + Claude Opus 5.5 (medium effort)

- 8 tests, each built twice with the same agent and model: once without DENT, once with DENT 2.0.
- **Average score: without DENT 37.9/50 · with DENT 43.8/50** (+5.9).
- **Automated checks:** all 7 web builds with DENT passed every automated gate; all 7 without DENT failed at least one (mostly text contrast; 3 kept animating under reduced motion; 1 unlabeled input).
- **Honesty:** 1 build without DENT invented social proof ("4.8 · 312 reviews"); 0 builds with DENT did.
- **Why the gap isn't bigger:** Opus 5.5 is a very strong model, so its pages are already good without help. DENT's gains show most in correctness (contrast, reduced motion, labels, honesty), distinctiveness (a real concept instead of the template look), and process (plans, design specs, self-checks). Expect a bigger gap with smaller or faster models; the first Gemini 3.8 Flash run is in `benchmark/results/brewlog-antigravity-gemini-3.8-flash-high-2026-11-14/`.
- **Caveats:** scores are by Claude Opus 5.5 (the same model family, and DENT's author), so they are not independent. Several with-DENT runs got a higher effort level or design feedback; see each test's Comparability line and `DEVIATIONS-claude-code-opus-5.5-medium-2026-11-14.md`.
